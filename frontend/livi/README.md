# LIVI Mobile

Application mobile Expo/React Native de LIVI.

## Développement local

```bash
npm install
npm start
```

API utilisée par l'application : `EXPO_PUBLIC_API_BASE_URL`.

Exemple :

```bash
EXPO_PUBLIC_API_BASE_URL=https://votre-api.example.com/api/v1
```

Les secrets et valeurs d'environnement réelles ne doivent jamais être commités.
