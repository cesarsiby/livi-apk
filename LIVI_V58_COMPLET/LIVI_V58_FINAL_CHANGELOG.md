# LIVI V58 — socle (prérequis V59)

V58 apporte le modèle marché, les délais de préparation, la disponibilité, la conservation et le modèle interville. Les incohérences identifiées ensuite sont corrigées par V59 ; le script d’entrée recommandé est `apply_livi_v57_v59.py`.

Interville : V58 introduit les champs de coût et de garantie. La règle finale appliquée en V59 est : garantie partenaire = 10 % de la valeur marchandise, sans minimum de garantie ; transport facturé à l’acheteur = carburant + minimum de livraison 1 000 XOF + charges configurées.
